# Эвосфера — песочница эволюции

Браузерная 3D-игра для смартфонов: конструируйте животных и растения, заселяйте ими
процедурный мир и наблюдайте, как из наследственности, мутаций и естественного отбора
сама собой возникает эволюция — появляются, меняются и вымирают целые виды.

Игра написана на HTML5, CSS и JavaScript (ES-модули), графика — Three.js / WebGL,
звук — Web Audio API. Сборка не нужна, внешних зависимостей во время работы нет
(Three.js лежит в `vendor/`).

## Как запустить

Игре нужен любой статический веб-сервер (ES-модули не загружаются с `file://`).

**На телефоне** — проще всего включить GitHub Pages для этого репозитория
(Settings → Pages → ветка с игрой, папка `/`) и открыть выданный адрес в мобильном
браузере. Через меню браузера игру можно «Добавить на главный экран».

**На компьютере:**

```bash
npx serve .
```

или

```bash
python3 -m http.server 8080
```

и открыть `http://localhost:8080`.

## Android-приложение (APK)

Готовый файл — [`dist/Evosphere.apk`](dist/Evosphere.apk). Это тонкая оболочка
(`android/`): полноэкранный WebView, который отдаёт файлы игры из ресурсов приложения,
поэтому игра работает без интернета. APK подписан отладочным ключом, для установки
нужно разрешить установку из неизвестных источников. Требуется Android 7.0 или новее
с актуальным системным компонентом WebView.

Пересборка без Gradle (нужны `build-tools` 35+ и `android.jar` из Android SDK, JDK 17+):

```bash
BUILD_TOOLS=$ANDROID_HOME/build-tools/35.0.0 ANDROID_JAR=$ANDROID_HOME/platforms/android-34/android.jar tools/build-apk.sh
```

## Управление

| Действие | Сенсорный экран | Мышь |
| --- | --- | --- |
| Перемещение по миру | один палец | левая кнопка |
| Масштаб | щипок двумя пальцами | колесо |
| Поворот и наклон камеры | поворот и сдвиг двумя пальцами | правая кнопка |
| Информация об организме | касание | щелчок |

Клавиатура: пробел — пауза, `1`–`4` — скорость времени.

## Что есть в игре

- **Редактор животных**: тело, ноги, голова, рот, органы чувств, покровы, крылья,
  плавники, окрас, биология и инстинкты. Внешность определяет способности: длина ног —
  скорость, рот — рацион, покров — переносимость температуры, крылья и масса — полёт.
- **Редактор растений**: деревья, кустарники, травы, водные растения и грибы; корни,
  крона, цветы, плоды, семена, требования к теплу, воде и свету.
- **Генетика**: у каждой особи свой геном (50 генов у животных, 27 у растений),
  скрещивание, мутации, гибриды близких видов, видообразование и родословное древо.
- **Экосистема**: растения конкурируют за свет, воду, питательные вещества и место;
  животные ищут пищу, пьют, спят, убегают, охотятся, ищут партнёра и растят потомство.
  Травоядные, всеядные, хищники, падальщики, детритофаги и грибы-разлагатели замыкают
  круговорот веществ.
- **Мир**: генератор с настройкой размера, рельефа, воды, температуры, влажности,
  разнообразия биомов и растительности; 10 биомов; день и ночь, сезоны, дождь, снег,
  засухи, изменение уровня воды и климата; пожары, наводнения, метеориты, извержения,
  эпидемии.
- **Время**: пауза, 1×, 3×, 10×, 40× и перемотка на годы вперёд с отчётом об изменениях.
- **Статистика и энциклопедия**: графики численности, пищевая сеть, карта
  распространения, причины гибели, журнал событий, карточки видов с генами и историей.
- **Сценарии**: шесть обучающих заданий — от первого травоядного до ледникового периода.
- **Сохранения**: автосохранение и три слота в памяти браузера, экспорт и импорт файлом,
  библиотека собственных видов, общая для всех миров.

## Устройство проекта

```
index.html, css/style.css     разметка и мобильный интерфейс
vendor/                        Three.js (MIT)
src/main.js                    игровой цикл, инструменты, перемотка
src/Simulation.js              связывает системы мира; работает и без графики
src/world/WorldGenerator.js    рельеф, климатические карты, биомы
src/world/TerrainSystem.js     запросы высоты, поля клеток (вода, почва, снег, огонь)
src/world/ClimateSystem.js     сутки, сезоны, погода, уровень воды, катастрофы
src/life/GeneticsSystem.js     гены, фенотип, скрещивание, мутации
src/life/OrganismSystem.js     особи, виды, пространственные сетки
src/life/BehaviorSystem.js     чувства, инстинкты, решения, движение
src/life/EcosystemSystem.js    рост и конкуренция растений, семена, разложение
src/life/EvolutionSystem.js    размножение и видообразование
src/systems/                   статистика, сохранения, звук, сценарии
src/render/RenderingSystem.js  сцена, небо, вода, инстансинг, уровни детализации
src/render/CreatureBuilder.js  процедурные модели животных
src/render/PlantBuilder.js     процедурные модели растений
src/render/AnimationSystem.js  процедурные анимации
src/ui/                        MobileUI, редакторы, статистика, энциклопедия
tools/                         прогон симуляции в Node.js без графики
```

Производительность: пространственные сетки для поиска соседей, обновление растений
и клеток мира порциями, редкое и разнесённое по времени «мышление» животных (у далёких
от камеры — ещё реже), один `InstancedMesh` на вид, анимированные модели только для
ближайших особей, пулы объектов, три уровня качества графики с автоподбором.

## Проверка баланса без графики

```bash
node tools/headless.mjs 6      # 6 лет симуляции со сводкой по видам
node tools/multi.mjs 10        # 10 лет на нескольких мирах
```
